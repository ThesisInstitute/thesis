# S.3596, both legs measured — the synthesis

Two independent measurements of the same bill landed today:

**Mechanical leg** (PR #64, D. Trimmer): S.3596 priced on certified Populace
build P via the validated PolicyEngine call path — budgetary impact −$1.83B;
child poverty **−0.20pp absolute** (17.02% → 16.82%; stated as −1.2% in the
PR per PolicyEngine's relative-change convention); gains bottom-concentrated
(D1 +$31.90/yr vs D10 +$0.30/yr). Certified stack policyengine-us==1.764.6 on
build P.

**Forecast leg** (this study): opus-5 and fable-5, conditioned on enactment,
forecasting the Census-published SPM child poverty rate for CY2027 against the
registered target `census.spm.child_poverty_rate.2027`: **−0.10 to −0.15pp**
(medians of 3 reps; mechanical grounding table in-prompt).

**Read consistently, the two legs land within a factor of two** (forecast leg
concedes one-half to three-quarters of the mechanical effect). Measure
universes differ — PE's poverty measure on build P for 2026 vs the Census SPM
child rate for realized 2027 — so exact agreement is not expected in either
direction. The forecast leg's attenuation is consistent with the
recall-anchoring mechanism (RESULTS §3a) but is NOT the dramatic version of
it; the order-of-magnitude divergence in this study appears elsewhere — the
harness envelope, where the name-only context moves the same delta to −1.5pp
(RESULTS §9 / envelope arm).
